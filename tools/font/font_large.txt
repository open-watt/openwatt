# OpenWatt bitmap font -- LARGE (upper, lower, digits, punctuation)
#
# Cell: 16 rows.  Row 0 and row 15 are pad; rows 1-14 are ink.
#
#   row  0  pad (line spacing)
#   row  1  cap top / ascender top      (b d f h k l, and all capitals)
#   row  5  x-height top                (a c e m n o r s u v w x z)
#   row 11  baseline -- last ink row of 'A', 'x', '0'
#   row 12  descender top               (g j p q y, comma, semicolon)
#   row 14  descender bottom / underscore
#   row 15  pad
#
# Cap height 11px, x-height 7px, descender 3px, 1px stems.
#
# The drawn width IS the glyph width; the renderer inserts exactly one blank
# column between glyphs, so do not draw side bearings.
#
# '#' = lit pixel, ' ' = clear.  Edit between the '|' bars.  To change a
# glyph's width, change every one of its 16 rows by the same amount; the
# parser rejects a glyph whose rows disagree.
#
# Lines starting with '#' outside a glyph block are comments.
# Blocks are:   U+XXXX  'c'  name
#               |  ...  |   x16
