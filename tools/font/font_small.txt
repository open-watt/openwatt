# OpenWatt bitmap font -- SMALL (caps, digits, punctuation)
#
# Covers all of printable ASCII (0x20-0x7E), plus three symbols above it:
# 0x7F ohm, 0x80 down chevron (the upside-down '^'), 0x81 degree, 0x82 bolt,
# 0x83 check, 0x84 sun, 0x85 middot, 0x86 times, 0x87 plus-minus, 0x88 no-break space
# (same bitmap as space, but not a line-break opportunity).  Up/left/right
# reuse '^' '<' '>', which are drawn as chevrons centred on row 3 to match.
#
# Cell: 8 rows.  Rows 0-6 are ink (7px cap height), row 7 is the line pad
# (and the only descender row -- comma and underscore use it).
#
#   row 0  cap / digit top
#   row 6  baseline (last ink row of a capital)
#   row 7  pad / descender
#
# The body is 4 wide.  Width 5 is reserved for glyphs that need an odd width
# for a centred stem (T V X Y + * ^ and the down chevron) or a wider body
# (M W # $ % & @).  All ten digits are 4 wide so numeric readouts stay
# column-aligned except '1', which is 3; 'I' is 3.
#
# The drawn width IS the glyph width; the renderer inserts exactly one blank
# column between glyphs, so do not draw side bearings.  There is no lowercase
# art: the generated offset table points 'a'-'z' at 'A'-'Z', so the renderer
# needs no case folding.
#
# '#' = lit pixel, ' ' = clear.  Edit between the '|' bars.  To change a
# glyph's width, change every one of its 8 rows by the same amount; the
# parser rejects a glyph whose rows disagree.
#
# Lines starting with '#' outside a glyph block are comments.
# Blocks are:   U+XXXX  'c'  name
#               |  ...  |   x8
